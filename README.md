# Presupuesto Rápido

Estimador rápido de costes de reformas (España, EUR). Eliges servicios, pones cantidades y ves el rango mínimo / recomendado / máximo con descuento, imprevistos e IVA. Admite extras manuales (nombre opcional, precio y m²).

- `index.html`: versión independiente. Se abre en cualquier navegador o hosting estático; guarda tarifas y presupuesto en el navegador (localStorage).
- `artifact.html`: versión para claude.ai Artifacts. Guarda tarifas y presupuesto en la nube del artifact (capacidad `db`).

Los precios incluidos son rangos orientativos editables, no tarifas verificadas. Los servicios sin tarifa aparecen como pendientes y no suman 0 €.
